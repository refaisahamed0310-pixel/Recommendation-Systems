# Recommendation Systems

A collection of Python-based recommendation system projects exploring content-based filtering, item similarity, collaborative filtering concepts, and recommendation dataset generation.

The notebooks use Pandas and Scikit-learn to prepare data, calculate similarity scores, and generate recommendations from movie, book, course/trainer, and vehicle datasets.

## Projects

| Project | Approach | Overview |
|---|---|---|
| Content-Based Movie Recommendation | TF-IDF, Cosine Similarity | Recommends items using genre/content text |
| Movie Collaborative Recommendation | Item-item similarity, Cosine Similarity | Finds movies with similar streaming-platform feature patterns |
| Book Recommendation | TF-IDF, Cosine Similarity | Recommends books using descriptions |
| Course-Trainer Recommendation | Collaborative-style ratings, Cosine Similarity | Explores course/trainer rating patterns |
| Vehicle Company Recommendation | Collaborative-style ratings, Cosine Similarity | Generates vehicle-company suggestions from user rating patterns |
| Vehicle Ratings Dataset Generator | Synthetic data generation | Creates a sample user-by-vehicle ratings dataset |

## Technologies & Tools

- **Language:** Python
- **Data Handling:** Pandas, NumPy
- **Feature Extraction:** Scikit-learn TF-IDF Vectorizer
- **Similarity Measurement:** Cosine Similarity
- **Development:** Jupyter Notebook, Google Colab

## Concepts Covered

- Content-based recommendation
- Collaborative filtering concepts
- Item-item similarity
- TF-IDF text vectorization
- Cosine similarity
- User-item rating matrices
- Missing-value handling
- Synthetic dataset generation

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/Recommendation-Systems.git
```

2. Move into the project directory:

```bash
cd Recommendation-Systems
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Open a project notebook using Jupyter Notebook, JupyterLab, or Google Colab.

## Dataset Information

External datasets are not included in this repository. Add the required CSV files to the relevant project folder before running the notebooks.

| Project | Dataset file |
|---|---|
| Movie Collaborative Recommendation | `MoviesOnStreamingPlatforms_updated.csv` |
| Book Recommendation | `book.csv` |
| Course-Trainer Recommendation | `course_trainer_data.csv` (generated by the dataset notebook) |
| Vehicle Company Recommendation | `vehicle_data.csv` (generated by the dataset notebook) |

The content-based movie notebook and vehicle dataset generator use data created directly in the notebook.

## Notes

These notebooks are learning and portfolio projects. Some recommendation examples use small or synthetically generated datasets; their outputs demonstrate recommendation techniques and should not be interpreted as production-grade recommendation quality. Results depend on the dataset, feature representation, and rating patterns.
